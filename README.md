# כיפת ברזל: עושים חשבון עם איראן 🚀

משחק מתמטיקה אקשן בדפדפן — עצור טילים על ידי פתרון תרגילים מהיר.

## איך משחקים

- **תרגיל מתמטי** מופיע על כל טיל
- לחץ על **הסוללה** שמציגה את התשובה הנכונה כדי ליירט
- אם הטיל יגיע לקרקע — תאבד חיים

## רמות קושי

| רמה | פעולות | טווח מספרים |
|------|---------|-------------|
| קל | חיבור / חיסור | 1–10 → 1–30 |
| בינוני | חיבור / חיסור | 1–20 → 1–50 |
| קשה | כפל / חילוק | 1–20 |
| טירוף | כפל / חילוק | 1–50 |

הקושי עולה בהדרגה לאורך הגלים — שאלות מתחילות קלות ומתקשות.

## מערכת כרטיסים

יירוט טיל מיוחד מעניק **כרטיס** (לא אפקט מיידי).
הכרטיסים מופיעים בפינה — לחץ עליהם כדי להפעיל בעיתוי הנכון.

## מערכת לייזר

- כל יירוט מצליח מעניק **אנרגיה**
- רצף (streak) מהיר מאיץ את קצב הצבירה
- כשהאנרגיה מלאה — כפתור הלייזר נדלק
- הלייזר משמיד את כל הטילים הפעילים ומעניק כרטיסים
